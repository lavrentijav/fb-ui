  named set of Xray matchers an operator maintains once and reuses — ad domains,
  a country’s ranges, a bypass set — stored verbatim so Xray’s own prefixes keep
  working (geosite:, regexp:, full: for domains; CIDRs and geoip: for IPs). A

  inbounds of one panel is matched against the referenced lists and blocked,
